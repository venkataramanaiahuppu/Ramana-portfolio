# Uppu Venkata Ramanaiah — Portfolio

A modern, responsive cybersecurity portfolio built with HTML, CSS and JavaScript.

## Run locally

1. Extract the project.
2. Open `index.html` in your browser.

For VS Code, you can install the **Live Server** extension and use **Open with Live Server**.

### Add your photo

Create an `images` folder:

```text
portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── images/
    └── profile.jpg
```

Then replace the `.photo-placeholder` in `index.html` with:

```html
<img src="images/profile.jpg" alt="Uppu Venkata Ramanaiah">
```

## Deploy on GitHub Pages

1. Create a GitHub repository named `portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and your `images` folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/root`, then Save.
6. GitHub will give you a live URL.
